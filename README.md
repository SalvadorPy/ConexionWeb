# Conexión Web



### ¿Para que sirve?
Aplicación básica que sirve como guía  para dirigirte a un formulario en el cual puedes ingresar datos para la propuesta ambiental, y esta se guarda como un archivo de datos **PHP**

Se animó la pagina usando los elementos **CSS**, aparte de un diseño audaz y ordenado en sus secciones con un header. Donde la sección *Participa* es la que señala al formulario en cuestión.



### Tecnologías 🛠️
* HTML
* CSS
* UX
* Php
* Base de datos
* Formularios
### Cómo ejecutar
1.-Clona el Repositorio y abre el archivo _index.html_ (dentro de la carpeta **ConexionWeb** ) en el navegador de tu preferencia. 
``` bash
git clone https://github.com/SalvadorPy/ConexionWeb.git
```
